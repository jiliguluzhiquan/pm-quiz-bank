# 中南知了｜智慧教育产品经理专业笔试题库

> **当前版本：后台AI配置 + 固定答题界面。** 首次配置或更换模型时双击「配置AI.command」在Mac终端输入API Key；日常双击「开始刷题.command」即可刷题和AI判分。页面不包含任何API配置表单。左侧菜单独立滚动，右侧答题面板固定，长答案只在右侧内容区内部滚动。全部1264道题及原有错题二刷功能保持不变。详见「升级说明_AI判分与错题二刷.md」。

版本：2026-11-13。共 **1264道原创模拟题，21个模块，五种题型**。本资料根据你提供的BOSS直聘岗位截图、正式公告截图和专业笔试题型短信设计，**不属于官方真题或官方考试大纲**。

## 最简单的使用方法

1. Mac访达 → 文稿（Documents）→ 本题库文件夹。
2. **首次使用AI时**，双击「配置AI.command」，按终端提示设置API Base URL、模型与密钥；密钥隐藏输入并保存在Mac钥匙串，不在前端页面出现。
3. **日常刷题**，双击「开始刷题.command」，会打开本地 http://127.0.0.1:18765/ 页面。终端窗口保持运行即可使用AI判分和本机进度同步。
4. 完全离线使用时，仍可直接双击「打开刷题系统.html」；AI判分不在离线文件模式运行。
5. 支持专题与题型筛选、随机60题模考、错题二刷、已掌握错题、收藏、主观与实操题参考评分以及导出/导入进度。建议定期导出JSON备份。

## 本地文件说明

- **配置AI.command**：仅首次或换模型时运行的后台安全配置入口，密钥不经过网页。
- **开始刷题.command**：推荐日常使用，启动本机网页、进度持久化与AI判分。
- **打开刷题系统.html**：无需启动服务的完全离线刷题入口（不支持调用AI）。
- **全部题目与答案.md**：完整文字知识库，可导入支持Markdown的知识管理工具。
- **分章节Markdown/**：21个专题独立文件。
- **中南知了_产品经理题库.jsonl**：知识库/RAG批量导入，单行一题。
- **中南知了_产品经理题库.csv**：可使用Numbers、Excel查看，UTF-8 BOM。
- **中南知了_产品经理题库.sqlite**：SQLite结构化库及FTS5 trigram索引。
- **搜索题库.py**：终端全文关键词搜索，能查询两个汉字的短中文词。
- **14天冲刺复习计划.md**：按优先级复习的日程表。
- **source/**：题目生成器、200个案例种子与60道实操题源材料。

示例搜索命令：

    cd ~/Documents/中南知了_智慧教育产品经理笔试题库_20261113
    python3 搜索题库.py "RAG" --limit 10
    python3 搜索题库.py "错题" --type 主观题
    python3 搜索题库.py "监护人" --module M18
